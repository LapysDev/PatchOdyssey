# Patch Odyssey
Inspired by [Patch Quest](https://www.polygon.com/reviews/23630629/patch-quest-review-roguelike-metroidvania-pokemon-steam), following the footsteps of [Palworld](https://www.pocketpair.jp/palworld), resembling the style of [Pokémon](https://www.pokemon.com/uk),
</br> </br>
<b style="font-variant: small-caps">Patch Odyssey</b> is an academic love letter to these awesome games series, and takes you on a familiar adventure through the world of cute &amp; deadly monsters in <b style="font-variant: small-caps">Patchlantis</b>.
